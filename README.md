# Заявки на ремонт — тренировка

Учебный проект: управляющая компания принимает заявки от жильцов.
Вся защита живёт в базе (Supabase/Postgres): гранты + RLS + триггеры.

Устроен так же, как `construction-crm`, но предметная область и пара правил другие.

## Структура

```
supabase/
  migrations/
    001_schema.sql          схема: роли, профили, заявки, история
    002_status_machine.sql  машина статусов: триггеры + RPC
    003_rls.sql             доступ: гранты + RLS
  seed.sql                  демо-данные
  tests/attacks.sql         тесты доступа «в обход интерфейса»
```
